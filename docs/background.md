其实 sample.html 填写表单、产出Excel的功能，只是我的“自动化内部控制评价测试系统”的最后一步。
现实世界 人工测试的整体流程：根据某个业务场景 找到对应的规章制度文件、测试材料样本，拆解出“测试步骤”，然后执行这些步骤应用于每个“测试材料样本”进行检查，以对“内部控制”业务进行“评价测试”，产物就是Excel表格，称为“测试工作底稿‘。(图中是“餐食采购”业务场景的一次测试工作产出)
我们这系统就希望自动化这套流程：选择某个业务场景，上传或选择规章制度文件、测试材料样本，自动识别或填写测试步骤，自动执行或人工执行步骤于每个样本，自动填写或人工填写工作底稿，底稿归档。
这个系统，日后能够做到有数据库存储和LLM API后端、AI Agent API后端(这是重头戏。因为规章制度PDF文件中描述了一些控制点以及额外测试流程，需要智能体理解规章制度流程 设计测试计划 执行步骤 检查测试材料；测试材料可能是多个PDF文件，其中有些签名、描述需要检查是否缺失或合规填写)
